# Registering!

You need to register to use PostyFox, as it's an online service, which is how you are able to use this from ... your PC, your iPad, your Android Tablet, your Phone ... anywhere!&#x20;

Head over to [https://app.postyfox.com](https://app.postyfox.com/) and you will be prompted with the Login page - at the bottom of this is a link to register. If you'd rather get in on the early action, we do have a development site too, but this will _often_ be broken, but it's where you will get to see (and influence) the latest development. This can be found at [https://dev.postyfox.com](https://dev.postyfox.com/).  If you are going to use this one, I'd strongly recommend being in our Discord, mainly so you can let us know what does (and doesn't!) work.
