# 🦊 Welcome to PostyFox

## Overview

PostyFox is not very imaginatively named, I know. But hey, I'm a techie fox, not a marketing guru.

{% hint style="info" %}
**PostyFox started out life as a fork of PostyBirb.**

The original v3 PostyBirb+ code can be found [here](https://github.com/mvdicarlo/postybirb-plus).\
PostyBirb has now moved onto v4, which has a LOT more features that the original v3 had, and it can be found as an "Alpha" [here](https://github.com/mvdicarlo/postybirb/releases).
{% endhint %}

Originally, I had planned to just extend PostyBirb, add in some things that I felt were missing and leave it at that.

But as time went on, I started heading in a different direction, then totally re-wrote what I'd done. And PostyFox as-it-is was born. A totally web based, web first, approach to posting your content. Don't get me wrong, I am still planning on adding a plugin to PostyBirb to allow it to integrate, as it is a **BRILLIANT** tool, and honestly, if you _dont_ need to post from your iPad, Phone or what-not, I'd **MASSIVELY** recommend using it.
