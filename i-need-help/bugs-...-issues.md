# Bugs ... Issues

If you have a found a bug, or an issue with PostyFox, first of all, please do not report it to the PostyBirb+ / PostyBirb project.

Please go to the [Github project page](https://github.com/PostyFox/postyfox-core/issues) and create an issue.

If you don't have a Github account, or don't want to go through that process, then you are welcome to send me bug report information on Discord to "aneillans".

When you submit a bug, please make sure you:

* Give all log files that are available - but do make sure you check and redact anything you need to!
* Give any screenshots that show any errors that are going to help
* Provide as much information as you can - sometimes even the content can be helpful, but please do not post any sensitive or explicit content to Github!&#x20;
* If you are hitting an error posting, please be sure to give us the Post ID that is present on the screen for your post; this will let us find the logs for your post!&#x20;
